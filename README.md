# Математика та фізика в Польщі та Україні / Matematyka i fizyka w Polsce i Ukrainie

Двомовний адаптивний веб-сайт для навчання математики та фізики українською та польською мовами.

## 🌟 Особливості

- ✅ **Двомовність**: Повна підтримка української та польської мов з легким перемиканням
- ✅ **Адаптивний дизайн**: Оптимізовано для ноутбуків, планшетів та смартфонів
- ✅ **Сучасний інтерфейс**: Красивий дизайн з градієнтами та анімаціями
- ✅ **8 розділів навігації**: Окремі сторінки для різних тем та рівнів навчання
- ✅ **Контакти**: Іконки для зв'язку через телефон, Telegram, Email та Facebook
- ✅ **Легке редагування**: Простий спосіб змінювати текст на двох мовах

## 🚀 Як використовувати

1. Відкрийте `index.html` у веб-браузері
2. Використовуйте перемикач UA/PL у верхньому правому куті для зміни мови
3. Натискайте на картки навігації для переходу до різних розділів

## ✏️ Як редагувати контент

### Зміна тексту заголовків та контенту

Всі елементи з двомовним текстом мають атрибути `data-ua` (українська) та `data-pl` (польська). Щоб змінити текст:

1. Відкрийте потрібний HTML файл
2. Знайдіть елемент з текстом, який хочете змінити
3. Змініть значення в атрибутах `data-ua` та `data-pl`

**Приклад:**
```html
<h2 data-ua="Старий український текст" data-pl="Stary polski tekst">
    Старий український текст
</h2>
```

Змініть на:
```html
<h2 data-ua="Новий український текст" data-pl="Nowy polski tekst">
    Новий український текст
</h2>
```

⚠️ **Важливо**: Завжди змінюйте ОБИДВА атрибути (`data-ua` та `data-pl`) і текст між тегами!

### Зміна надписів на кнопках навігації

Відкрийте `index.html` та знайдіть секцію з кнопками навігації. Кожна кнопка має структуру:

```html
<a href="pages/basic-school.html" class="nav-card">
    <div class="nav-card-image">
        <img src="images/basic-school.jpg" alt="Basic School">
    </div>
    <h2 data-ua="Базова школа 1-8 класи" data-pl="Szkoła podstawowa klasy 1-8">
        Базова школа 1-8 класи
    </h2>
</a>
```

Змініть атрибути `data-ua` та `data-pl` в тезі `<h2>`.

### Додавання контенту на сторінки

Відкрийте будь-який файл зі сторінкою (наприклад, `pages/basic-school.html`) та знайдіть секцію `<main class="content-section">`. Додавайте новий контент, використовуючи двомовні атрибути:

```html
<h3 data-ua="Новий розділ" data-pl="Nowa sekcja">Новий розділ</h3>
<p data-ua="Український текст параграфа" data-pl="Polski tekst paragrafu">
    Український текст параграфа
</p>
```

### Зміна контактної інформації

В кожному файлі знайдіть секцію з контактними іконками та змініть посилання:

- **Телефон**: `href="tel:+48123456789"` - змініть номер
- **Telegram**: `href="https://t.me/yourusername"` - змініть username
- **Email**: `href="mailto:info@example.com"` - змініть email
- **Facebook**: `href="https://facebook.com/yourpage"` - змініть посилання

### Заміна зображень

Замініть файли у папці `images/` на свої власні зображення. Зберігайте ті самі імена файлів або оновіть посилання в HTML:

```html
<img src="images/basic-school.jpg" alt="Basic School">
```

Рекомендований розмір зображень: 400x300 пікселів.

## 🎨 Налаштування дизайну

Відкрийте `css/styles.css` та змініть кольорову схему у розділі `:root`:

```css
:root {
    --primary-color: #2c3e50;     /* Основний колір */
    --secondary-color: #3498db;   /* Додатковий колір */
    --accent-color: #e74c3c;      /* Акцентний колір */
    --text-color: #333;           /* Колір тексту */
    --bg-color: #f5f5f5;          /* Колір фону */
}
```
